# 导入课程包

外部课程通过 `.turnapack` 进入 Turna。LibreLingo 等社区课程的 YAML 源在离线工具中转换成 `.turnapack` 后，即可像内置课程一样学习、复习和管理。

包有两个版本：`turnapack/1` 是单个 JSON 文件（无媒体），`turnapack/2` 是带 `media/` 的压缩包。手工制作的纯 JSON 内容可以用 `.json` 扩展名导入，格式契约见[外部课程包](/authoring/course-pack)。

::: info 没有内置课程商店
应用不提供在线下载。`.turnapack` 文件需要自行转换（见[外部课程包](/authoring/course-pack)）或从他人处获得，再手动导入。
:::

## 导入步骤

1. 在学习页顶栏点击地球图标，进入「课程管理」。
2. 滚动到底部「添加课程」区，点击「导入课程包」。
3. 在文件选择器中选择 `.turnapack` 文件（手工制作的纯 JSON 包也可以是 `.json`）。
4. 等待进度走完：解析课程包 → 校验课程内容 → 写入课程库。
5. 成功提示会显示课程名、章节数与词条数，新课程随即出现在课程列表中。

导入包的 `language.code` 决定它在课程列表中的身份：两位或三位小写字母，且**不能占用内置课程的语言码**，也不能是保留字 `anki`。

## 重复导入与覆盖确认

对已安装的语言再次导入时，应用先弹出「替换现有课程？」确认：

- 新包中**仍然存在**的词条与内容，学习进度保留。
- 新包中**被移除**的内容，其复习进度、错题等记录一并清除。
- 点「取消」则不写入任何内容。

取消确认属于正常退出，不算导入失败。

## 卸载与恢复

- 在课程管理页可移除导入的课程，移除前需确认。
- 移除后语言出现在「已卸载的语言」区，可随时点「恢复」——应用保留了当时导入的 `.turnapack` 副本，恢复时重新解包播种，无需再找原文件。
- 如果保留的包文件不可用（例如系统清理了应用数据），会提示「无法恢复，需重新导入课程包」。

## 备份边界

备份覆盖课程数据库（含导入课程的学习记录与语言元信息），**不覆盖** `.turnapack` 包文件本身。换设备或清除应用数据后，需要重新执行一次导入。建议把原始 `.turnapack` 文件放在应用之外的备份位置，见[本地数据与隐私](/guide/data-and-privacy#备份原则)。

## 限制

- 导入课程的内容在应用内只读；不能用桌面课程编辑器修改，需要改动时重新生成并覆盖导入。
- 包内媒体（图片 / 音频）随导入解压到应用私有目录，仅在删除课程时清理。
- 没有音频媒体的包使用 TTS 朗读听力题，效果取决于设备 TTS 对目标语言的支持。
